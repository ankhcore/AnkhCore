| D22 | 2026-11-09 | **Fan control has two primary modes.** Manual: a user-set speed held through the NBFC CLI, fixed until the user changes it or the mode. Automatic: AnkhCore is the control brain using a configurable curve with smoothing, hysteresis and response delays, responding faster to rises than falls; SensorHub is the only temperature source and NBFC only the actuator. NBFC temperature is never used. NBFC Auto or Stop is not assumed to restore BIOS control. The NBFC config is preserved unless authorized. No hardware command or live test without explicit approval. | Owner 2026-11-09; `docs/design/FAN_CONTROL_NBFC.md` |
| D23 | 2026-11-09 | **Mandatory 40 % minimum fan speed in every mode**, enforced in control logic; lower or invalid requests clamp to 40 %; percent is not assumed to map to RPM. **Manual Thermal Override:** on a sustained dangerous SensorHub temperature, Manual is suspended, the saved target kept, fan speed raised up to the config's maximum, and `THERMAL PROTECTION ACTIVE — MANUAL CONTROL OVERRIDDEN` shown persistently. The target returns only after a separate recovery threshold and stable period, never below 40 %. Selected mode and control authority are distinct. Invalid readings during an override are a critical monitoring failure, with no silent return to Manual. Thresholds are configurable and unvalidated until approved hardware testing. This does not replace BIOS or firmware protection. Resolves P10. | Owner 2026-11-09; `docs/design/FAN_CONTROL_NBFC.md` |
